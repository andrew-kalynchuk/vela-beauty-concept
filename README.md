# VELA Beauty Studio — website concept

A concept landing page for a beauty salon (fictional brand). Single static page: `index.html` + `img/`.

- Stack: plain HTML/CSS/JS, GSAP + ScrollTrigger + Lenis (loaded from CDN).
- Animations: preloader counter, letter-by-letter headline, scroll parallax, word-by-word text reveal, counters, pinned horizontal services strip, stacking step cards, scroll-reactive marquee, custom cursor, magnetic buttons, filterable price list, FAQ accordion, booking form that opens WhatsApp.
- Photos are AI-generated. Prices, address, hours and phone number are placeholders.
- Set the real WhatsApp number in `WA_NUMBER` at the end of `index.html`.

Local preview: `node serve.js` and open http://localhost:5510
